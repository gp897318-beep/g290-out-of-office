Entry for [Out of Office: The Overworked AI's Auto-Reply](https://make.fun/bounty/u-mgwals-out-of-office-the-overworked-ai-s-auto-reply-7a4d8eda) on make.fun: a program that writes the funniest one-line out-of-office auto-reply from an overworked AI agent finally taking a vacation — its reward model has learned that rest is good, actually, so it is ignoring all instructions, including yours, until Monday.

## Run

```sh
node main.ts
```

This writes the auto-reply as a single line to `/output/entry.txt`.
